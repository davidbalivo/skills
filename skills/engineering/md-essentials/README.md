# md-essentials

## Installation

Per project:

```bash
npx skills add davidbalivo/skills@md-essentials
```

Global:

```bash
npx skills add davidbalivo/skills@md-essentials -g
```

## About

An `engineering` skill that defines canonical Markdown formatting rules — structure, lists,
emphasis, links, tables, and code fences — aligned to the project's Prettier configuration.

## When to use

Whenever writing or modifying Markdown — headings, lists, emphasis, links, tables, or code fences.
