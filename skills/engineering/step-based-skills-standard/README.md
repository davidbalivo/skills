# step-based-skills-standard

## Installation

Per project:

```bash
npx skills add davidbalivo/skills@step-based-skills-standard
```

Global:

```bash
npx skills add davidbalivo/skills@step-based-skills-standard -g
```

## About

An `engineering` skill that defines the canonical structure, keywords, tags and mermaid conventions for step-based skills.

## When to use

When migrating an existing step-based skill to the canonical format.
