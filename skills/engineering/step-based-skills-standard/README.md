# step-based-skills-standard

## Installation

Per project:

```bash
npx skills add davidbalivo/skills@step-based-skills-standard
```

Global:

```bash
npx skills add davidbalivo/skills@step-based-skills-standard -g
```

## About

An `engineering` skill that defines the canonical structure, keywords, tags and mermaid conventions for SDD-flow skills.

## When to use

On-demand only — do not auto-trigger. Invoke when authoring a new SDD-flow skill, or when migrating an existing one to the canonical step-based format.

## Invocation

`/step-based-skills-standard`
