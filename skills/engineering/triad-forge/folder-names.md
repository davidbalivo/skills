# Carpetas por tema

| Tema                      | Carpeta                 |
| ------------------------- | ----------------------- |
| Código                    | `code`                  |
| Datos y configuración     | `data-map`              |
| Logs y errores            | `logs`                  |
| Paridad legacy            | `legacy-parity`         |
| Normativa y APIs externas | `research`              |
| Historial                 | `history`               |
| Normativa                 | `regulation`            |
| Convenios colectivos      | `collective-agreements` |
| Formatos oficiales        | `official-formats`      |
| APIs y servicios externos | `third-party-services`  |
| Documentación interna     | `internal-docs`         |

Usa `research` para tareas generales que combinen normativa y APIs externas. Para un tema concreto, elige la categoría más específica.
