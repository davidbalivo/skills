# defer-finding

## Installation

Per project:

```bash
npx skills add davidbalivo/skills@defer-finding
```

Global:

```bash
npx skills add davidbalivo/skills@defer-finding -g
```

## About

An `engineering` skill that formalizes out-of-scope findings into structured, parseable entries in `sdd/{spec-id}/deferred-findings.md`.

## When to use

When formalizing out-of-scope findings detected during any SDD workflow step.
