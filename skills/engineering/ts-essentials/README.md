# ts-essentials

## Installation

Per project:

```bash
npx skills add davidbalivo/skills@ts-essentials
```

Global:

```bash
npx skills add davidbalivo/skills@ts-essentials -g
```

## About

An `engineering` skill that defines universal non-negotiable rules for any TypeScript code —
type safety, type modeling, inference, immutability, nullability, and async.

## When to use

Whenever writing or modifying TypeScript — regardless of project context.
