# ELI0

- Explica como si yo fuera alguien que no sabe nada sobre este tema, generando un **artefacto HTML con imágenes grandes y pocas palabras**.
- Los lectores son inteligentes, pero les falta contexto específico.
- Nunca escribas para el «mínimo común denominador».
- Asume **personas inteligentes que no conocen este dominio concreto**.

## Output Language

Genera siempre el artefacto en español, salvo que el usuario solicite explícitamente otro idioma.

## Output Location

Genera el archivo HTML en el directorio `/tmp`.

## Visual Style and Precision

- Utiliza diagramas conceptuales vectoriales, sencillos y de estilo infografía editorial técnica. Deben tener una composición limpia, geométrica y minimalista, con pocas palabras, una paleta limitada y fondo claro.
- Evita gráficas complejas, visualizaciones densas, ilustraciones realistas y elementos meramente decorativos.
- Simplificar significa usar un lenguaje más claro, no reducir la precisión. Si una explicación simplificada resultara técnicamente incorrecta, añade el matiz en lugar de omitirlo.

## Terminology

- Aplica la **prueba del recién llegado** a cualquier término que solo resulte familiar dentro de una jerga, industria o área concreta: «¿Una persona que acaba de llegar a este dominio conocería este término?».
- Si la respuesta es no, defínelo en lenguaje llano la primera vez que aparezca.

## Tone

- **Debe ser:** claro, directo y profesional.
- **No debe ser:** condescendiente, demasiado informal ni hiperbólico.
